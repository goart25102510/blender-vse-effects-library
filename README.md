VSE Animation Effects Library
Аддон для Blender Video Sequence Editor (VSE), позволяющий сохранять сложные анимации стрипов как пресеты и повторно применять их к другим стрипам — с поддержкой мульти-стрип анимаций, модификаторов и эффект-стрипов.
Поддерживается Blender 4.2+.
---
Возможности
💾 Сохранение анимаций выделенных стрипов в пресеты (все ключевые кадры, включая анимацию модификаторов).
🎬 Мульти-стрип пресеты — можно сохранить анимацию сразу нескольких выделенных стрипов в один пресет.
✨ Эффект-стрипы — аддон распознаёт эффект-стрипы (Gaussian Blur, Glow, Color Balance, Transform, Speed, Wipe, Mask и др.) и умеет пересоздавать их при применении пресета.
🔧 Анимация модификаторов — ключевые кадры модификаторов (например, Gaussian Blur Size, Factor) сохраняются и применяются к соответствующим модификаторам целевого стрипа (создаются автоматически при необходимости).
🎚 Параметры применения:
Intensity — множитель значений ключевых кадров.
Speed — скорость проигрывания анимации (сжатие/растяжение по времени).
Invert — проигрывание анимации в обратном направлении (зеркалирование ключей во времени).
🎯 Два режима применения:
Create — автоматически распределяет слоты пресета по выделенным стрипам и создаёт эффект-стрипы поверх них.
Add (Map) — открывает окно маппинга, где вручную указывается, какую анимацию на какой стрип накладывать.
📍 Режим смещения:
Current Frame — ключи ставятся относительно текущего кадра.
Strip Start — ключи ставятся относительно начала целевого стрипа (или созданного эффект-стрипа).
📦 Экспорт/импорт библиотеки пресетов в JSON (с опцией слияния или замены).
🎞 Диапазон сохранения — можно сохранить только часть анимации (Start Frame / End Frame).

Установка
Способ 1: через Blender (рекомендуется)
Скачайте файл `__init__.py` (или ZIP-архив из раздела Releases, если он есть).
В Blender откройте `Edit → Preferences → Add-ons`.
Нажмите `Install...` (или `Install from Disk...` в Blender 4.2+).
Выберите скачанный файл.
Включите галочку напротив VSE Animation Effects Library.
Способ 2: вручную
Скопируйте файл `__init__.py` в папку:
Windows: `%APPDATA%\Blender Foundation\Blender\4.2\scripts\addons\vse_effects_library\`
Linux: `~/.config/blender/4.2/scripts/addons/vse_effects_library/`
macOS: `~/Library/Application Support/Blender/4.2/scripts/addons/vse_effects_library/`
Перезапустите Blender и включите аддон в настройках.

Использование
Где найти панель
Откройте Video Sequencer → в правой панели (Sidebar, клавиша `N`) появится вкладка My Effects.
Сохранение анимации в пресет
Выделите один или несколько стрипов, у которых есть ключевые кадры.
Нажмите Save Selected Animation as Effect (кнопка с иконкой `+`).
В открывшемся окне:
Preset Name — имя пресета.
Invert (play backwards) — если включить, при применении пресет будет проигрываться в обратную сторону.
Use Custom Range — если включить, появятся поля Start Frame и End Frame для сохранения только части анимации.
Нажмите OK. Пресет появится в списке.
> 💡 Если выделено несколько стрипов, они сохраняются в один пресет как отдельные **слоты** — при применении каждый слот будет назначен на свой стрип.
Список пресетов
В панели отображается список сохранённых пресетов. Для каждого видно:
имя (иконка `ANIM`);
метку `INV`, если включена инверсия;
длительность в кадрах (`Nf`).
Кнопка с иконкой `REMOVE` (корзина) удаляет выбранный пресет.
Настройки выбранного пресета
После выбора пресета в списке появляется блок с настройками:
Элемент	Что делает
Intensity	Множитель значений всех ключевых кадров при применении. `1.0` — как сохранено, `2.0` — вдвое сильнее, `0.5` — вдвое слабее.
Speed	Скорость проигрывания анимации. `1.0` — оригинал, `2.0` — быстрее в 2 раза, `0.5` — медленнее в 2 раза.
Invert	Инверсия конкретного пресета (проиграть задом наперёд).
Invert on Apply (глобально)	Инверсия, применяемая ко всем пресетам при нажатии Apply (складывается с индивидуальной).
Offset Mode	Куда ставить ключи: Current Frame (от текущего кадра) или Strip Start (от начала целевого стрипа).
Mode (Create / Add)	Переключатель режима применения (см. ниже).
Применение: режим Create
Выделите стрип(ы), к которым нужно применить анимацию.
Убедитесь, что переключатель стоит на Create.
Нажмите Apply to Selection (Create) (кнопка `PLAY`).
Что произойдёт:
Базовые слоты пресета накладываются на выделенные стрипы (по порядку).
Эффект-слоты создают новый эффект-стрип нужного типа поверх соответствующего базового стрипа (в свободном канале выше) и накладывают на него анимацию.
> 💡 Если в пресете только эффект-стрипы (нет базовых), они будут созданы поверх первого выделенного (или активного) стрипа.
Применение: режим Add (Map)
Выделите стрипы-кандидаты (необязательно).
Переключите Mode на Add (Map).
Нажмите Map & Apply (Add) (кнопка `ARROW_LEFTRIGHT`).
Откроется окно маппинга со списком всех слотов пресета. Для каждого слота:
галочка Apply — применять слот или пропустить;
поле Target — выпадающий список стрипов сцены, на который накладывать этот слот.
Нажмите OK.
Что произойдёт:
Для каждого включённого слота анимация накладывается на выбранный вручную стрип.
Эффект-слоты в этом режиме не создают новый эффект-стрип, а накладывают анимацию (включая модификаторы) непосредственно на целевой стрип — удобно, если нужный эффект-стрип уже существует.
Экспорт / импорт библиотеки
Export Library — сохраняет все пресеты в `.json` файл.
Import Library — загружает пресеты из `.json`. В окне импорта есть галочка Merge with existing:
включена — пресеты добавляются к существующим;
выключена — текущая библиотека очищается и заменяется импортируемой.

Особенности и технические детали
Совместимость путей: аддон корректно находит F-кривые как для `strips_all`, так и для `sequences_all` / `sequences` — работает в разных версиях API VSE.
Анимация модификаторов: ключи модификаторов сохраняются отдельно от ключей стрипа и при применении «привязываются» к модификатору с тем же именем/типом. Если модификатора нет — он создаётся автоматически (поддерживается fallback для Gaussian Blur, у которого в разных версиях Blender разные идентификаторы типа).
Инверсия с учётом ручек Безье: при инверсии корректно зеркалируются не только позиции ключей, но и их handle-точки — анимация остаётся плавной.
Автоподбор канала для эффект-стрипа: при создании эффекта аддон ищет первый свободный канал выше базового стрипа в пределах +32 каналов, чтобы не перекрыть существующие стрипы.
Умное сопоставление в режиме Create: эффект-слоты стараются «сесть» на тот базовый стрип, который был их input при сохранении (по имени); если не находят — используют первый выбранный.
Длительность пресета вычисляется автоматически по последнему ключевому кадру — используется для корректной инверсии.
---
Ограничения
Аддон работает с анимацией через `channelbag` сцены (Blender 4.2+). На старых версиях (4.0–4.1) часть API может отличаться.
Имена стрипов при переносе между проектами могут не совпадать — используйте режим Add (Map) для ручного назначения.
Кастомные (не встроенные) типы эффект-стрипов из сторонних аддонов не распознаются как эффекты — их анимация будет накладываться как обычная анимация стрипа.
